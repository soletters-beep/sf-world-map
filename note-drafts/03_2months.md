# 離れて暮らす親のための赤ちゃん成長ガイド〈2ヶ月〉

予防接種が本格的にスタートする月。ここから接種スケジュール管理という新しい負担が始まります。

## 1. この時期の目安

- 体重増加は引き続き1日20〜30g程度が目安です。
- **社会的微笑**：あやすと笑い返すような表情が見られ始める時期です。

## 2. 起こりやすいイベント・変化

- 生活リズムが少しずつ整い始める子もいますが、個人差が大きい時期です。

## 3. 予防接種

**生後2ヶ月からワクチン接種が本格的に始まります。** 標準的なスケジュールは以下の通りです（自治体・医療機関により順序が前後することがあります）。

- 五種混合ワクチン（百日せき・ジフテリア・破傷風・不活化ポリオ・Hib）1回目
- 小児用肺炎球菌ワクチン 1回目
- B型肝炎ワクチン 1回目
- ロタウイルスワクチン 1回目

同時接種になることが多く、接種当日〜翌日は発熱や注射部位の腫れが出ることがあります。詳細な間隔・回数は自治体の予診票・かかりつけ医の案内が最新かつ正確です。

## 4. 気をつけたい病気・症状

- 予防接種後の発熱は数日でおさまることが多いですが、機嫌や哺乳の様子と合わせて経過を見ます。

## 5. 事故・注意点

- 引き続きあおむけ寝、うつぶせでの窒息リスクに注意します。

## 6. お母さんにかかる負担

- **通院回数が増える負担**：複数のワクチンを予定通り受けるためのスケジュール管理、通院そのものが大きな負担になります。特にワンオペで通院する場合、赤ちゃんを連れての移動・待ち時間の管理は体力的にも大きいです。
- 睡眠不足はまだ続いている時期です。

## 7. 離れているからこそ聞いておきたい質問リスト

- 予防接種は始まった？何のワクチンを受けた？
- 接種後に発熱や機嫌の変化はあった？
- 通院、一人で大変じゃない？付き添える人はいる？
