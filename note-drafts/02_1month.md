# 離れて暮らす親のための赤ちゃん成長ガイド〈1ヶ月〉

新生児期を抜けて、生活のリズムが少しずつ見えてくる時期。この回の主役は「1ヶ月健診」です。

## 1. この時期の目安

- **体重増加**：0ヶ月に続き、1日あたり25〜30g程度の増加が目安です。
- **1ヶ月健診**：生後1ヶ月前後で、赤ちゃんとお母さんの両方が健診を受けます。赤ちゃん側は体重・身長・黄疸の有無・股関節の状態（先天性股関節脱臼のチェック）などを確認し、お母さん側は子宮の戻り具合や傷の治り、心身の状態を診てもらいます。

## 2. 起こりやすいイベント・変化

- **乳児湿疹・脂漏性湿疹**：顔や頭にポツポツやかさぶたのような湿疹が出やすい時期です。ホルモンの影響によるもので、多くは生後数ヶ月で自然に落ち着きます。
- **外気浴の開始**：沐浴から少しずつ外気浴・短時間の散歩に移行していく目安の時期です。

## 3. 予防接種

1ヶ月時点ではまだ本格的な接種は始まりません。**生後2ヶ月から複数のワクチンが同時にスタートする**ため、このタイミングで自治体から届く予診票・母子手帳を確認し、かかりつけの小児科を決めておくと2ヶ月目にスムーズです。

## 4. 気をつけたい病気・症状

- 発熱時の対応は0ヶ月と同じく、**生後3ヶ月未満は38℃以上の発熱で即受診**が基本です。
- 黄疸が長引いている場合は1ヶ月健診で相談するタイミングです。

## 5. 事故・注意点

- 抱っこ紐やベビーラックの使用時、うつぶせや顔が埋もれる体勢にならないよう注意が必要です。
- 引き続きあおむけ寝を基本とします。

## 6. お母さんにかかる負担

- **産褥期がまだ続いている**：出産から1ヶ月時点でも、子宮の戻りや悪露が完全に終わっていないことがあります。1ヶ月健診はその回復度合いを確認する重要な機会です。
- **里帰りから自宅に戻るタイミング**：里帰り出産だった場合、この時期に自宅へ戻ることが多く、サポートが減る分、負担が急に増えることがあります。
