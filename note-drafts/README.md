# 離れて暮らす親のための赤ちゃん成長ガイド（note連載）

## 目的

離れて暮らす我が子のことを、もっと知りたくて始めた連載。

会える時だけ「可愛いね」と抱っこして、お世話はぎこちなくて、結局あまり役に立てない敗北感。
「予防接種いつ受けるか分かる？」「今どんな病気が流行ってるか知ってる？」と聞かれて何も答えられなかった悔しさ。

一緒に暮らしていれば自然と分かることを、月齢ごとに整理していく。まず自分のための記録・勉強ノート。

## 各回の共通フォーマット

1. この時期の目安（体重・授乳・睡眠など）
2. 起こりやすいイベント・変化
3. 予防接種
4. 気をつけたい病気・症状（見分け方・受診の目安）
5. 事故・ヒヤリハット注意点
6. お母さんにかかる負担
7. 離れているからこそ聞いておきたい質問リスト（赤ちゃん／お母さん）
8. 参考情報源（一次情報でファクトチェック）

## 制作ルール

- 数値・医学的判断は必ず一次情報（厚労省、日本小児科学会、医師監修記事など）で裏取りしてから書く
- 自分は医師ではない立場を明記し、最終判断はかかりつけ医・母子手帳・自治体案内を優先する旨を書く
- 「ノウハウ」ではなく「自分のための記録」というトーンを崩さない

## 1歳以降の投稿方針

0ヶ月〜1歳の連載が完結したあとは、月齢の節目ではなく**テーマ単位の投稿**に切り替える。子どものこと（発達、病気、予防接種、事故防止など）と、母親のこと（体調、負担、心理的な変化、夫婦関係など）を、テーマを問わず1日1本のペースで書き足していく。

運用は完全にローカル（Mac + ローカルClaude Code）に移行済み。`note-drafts/daily_write.sh` を、毎日20時に起動するlaunchdジョブから実行し、まだ書いていないテーマを1本ずつ自動生成する運用にする。クラウドセッション側の自動リマインダーは削除済み。
