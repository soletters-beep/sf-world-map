# 離れて暮らす親のための赤ちゃん成長ガイド〈12ヶ月・1歳〉

1歳の誕生日。この1年の集大成であり、次のフェーズへの節目です。

## 1. この時期の目安

- **一人歩きの目安（生後12〜15ヶ月）**に入ります。まだ歩かなくても、この時期からの数ヶ月で歩き出す子がほとんどです。
- 離乳食は完了期（12〜18ヶ月、3回食＋おやつ）に移行し、大人の食事に近づいていきます。

## 2. 起こりやすいイベント・変化

- **1歳の誕生日・1歳健診**：この1年の成長を振り返る節目です。

## 3. 予防接種

**1歳はワクチン接種のもう一つの山場です。** 標準的には以下のようなワクチンが対象になります（自治体・医療機関の案内で最終確認してください）。

- 麻しん風しん混合ワクチン（MRワクチン）1期
- 水痘ワクチン
- おたふくかぜワクチン（任意接種）
- 五種混合ワクチン4回目
- 小児用肺炎球菌ワクチン4回目

複数を同時接種することが多く、事前にスケジュールを立てておくと安心です。

## 4. 気をつけたい病気・症状

- 歩き始めると転倒による怪我が増えます。発熱時の対応は、3ヶ月未満ほどの緊急性ではないものの、機嫌や哺乳・食欲の様子を見て判断する姿勢は引き続き大切です。

## 5. 事故・注意点

- 歩行開始に伴い、段差や階段、玄関周りでの転倒リスクが増えます。行動範囲がさらに広がるため、家全体の安全対策の総点検をするタイミングでもあります。

## 6. お母さんにかかる負担

- **卒乳・保育園入園・職場復帰が重なる節目**：多くの家庭でこの3つが同時期に集中し、負担が一気に増えるタイミングです。
- この1年、慢性的な睡眠不足と休みのない生活が続いてきました。1歳という節目は、赤ちゃんだけでなくお母さん自身の1年を労う機会でもあります。
